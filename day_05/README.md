# Day 5 - JavaScript

## Objective

To learn modern JavaScript concepts, asynchronous programming, and API data handling through practical exercises and an Employee Dashboard.

## Topics Covered

- Variables, Data Types, Functions and Arrow Functions
- Arrays, Objects, Destructuring, Spread and Rest
- Template Literals and Array Methods
- Scope, Closures and Hoisting
- Callbacks, Promises and Async/Await
- Event Loop, Modules and Error Handling
- Fetch API and JSON

## Employee Dashboard

A simple web-based Employee Dashboard developed using HTML, CSS and JavaScript.

### Features

- Employee listing
- Search and department filter
- Salary sorting
- Employee details
- Add, edit and delete employees
- JSON data handling using Fetch API

## Technologies

HTML | CSS | JavaScript | JSON | Fetch API
