# Day 2 - Python Development & Data Analysis

This project is part of the **10-Day Intern Technical Training Program**.

## Contents

### 1. Python Exercises

Includes basic Python programs covering:

- Variables and Data Types
- Lists, Tuples, Sets and Dictionaries
- Conditions and Loops
- Functions
- Lambda and List Comprehensions
- Modules and Packages
- Exception Handling
- File Handling
- Classes, Objects and Inheritance
- JSON File Reading and Analysis

### 2. Student Management System

A simple Python-based Student Management application with:

- Add Student
- Update Student
- Delete Student
- Search Student
- Filter Students
- Sort Students
- Student Statistics
- JSON Data Storage
- Exception Handling

### 3. CSV Analysis

A Python-based CSV data analysis program that provides:

- Record Count
- Missing Values
- Duplicate Records
- Average Marks
- Minimum and Maximum Marks
- Department-wise Statistics
